# Canonical license references

This collection includes the CERN-OHL-P hardware-license text and uses
canonical standard texts/URLs for the other licenses. Project-level notices
identify the material placed under each license:

- [MIT License](https://spdx.org/licenses/MIT.html) — software and firmware; the full text is in each project's `LICENSE` file.
- [CERN-OHL-P-2.0](CERN-OHL-P-2.0.txt) — hardware design source and the manufacturing deliverables made from it.
- [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.en) — original written documentation and original images/diagrams.

The official online sources are the [OSI CERN-OHL-P page](https://opensource.org/license/CERN-OHL-P-2.0)
and the [Creative Commons CC BY 4.0 legal code](https://creativecommons.org/licenses/by/4.0/legalcode.en).
Do not alter the standard license text or use the CERN or Creative Commons
trademarks to imply endorsement.
