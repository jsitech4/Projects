Administrator password

Changing this password signs out all local sessions. Saved network settings and measurements remain intact.

The developer password is a master recovery credential. Keep it separate from client credentials.Use 12–96 printable characters with uppercase, lowercase, a digit, and a symbol.

If neither credential is available, recovery requires authorized physical service with the device's service credential. Restarting does not reset authentication.
